# SMART IA TRADING ALEX

**Advanced AI-Powered Algorithmic Trading Platform**

A professional-grade automated trading system with machine learning capabilities, real-time market analysis, and intelligent risk management.

## 🎯 Core Features

- **Autonomous AI Trading Engine** - Real-time market analysis and automated order execution
- **Multi-Asset Support** - Trade multiple pairs simultaneously with adaptive lot sizing
- **Scalping & Swing Trading** - Automated strategy selection based on market conditions
- **Continuous Learning** - ML models improve with every trade
- **MetaTrader 5 Integration** - Live connection via custom EA robot
- **Enterprise Security** - 2FA, role-based access, audit trails
- **Professional Dashboard** - Real-time monitoring and analytics

## 📁 Project Structure

```
smart-ia-trading-alex/
├── backend/                 # Node.js API & Core Engine
├── frontend/               # React Dashboard
├── ai-engine/             # Python ML Pipeline
├── ea-robot/              # MQL5 MetaTrader 5 Robot
├── docker-compose.yml     # Containerization
├── docs/                  # Technical Documentation
└── deployment/            # Production Configuration
```

## 🚀 Quick Start

```bash
git clone https://github.com/destinbyoto-ctrl/smart-ia-trading-alex.git
cd smart-ia-trading-alex
```
